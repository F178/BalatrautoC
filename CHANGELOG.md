# Changelog

## 0.6.0

- Added automatic multi-scale card and square-icon region proposals.
- Added direct visible-window capture for `Balatro.exe` on Windows.
- Added ranked detected-region overlays and a candidate selector in Seed Lab.
- Preserved whole-image matching so clean crops retain exact confidence.
- Filtered internal extraction-only asset classes out of the general recognition view.
- Added a region-detector regression suite and a repeatable Visual Studio build helper.

## 0.5.0

- Added deterministic extraction of 410 game-art references from local Balatro files.
- Added original art to seed analysis, shop queues, pack queues, and clue previews.
- Added local image recognition with asset filters, ranked confidence, and explicit confirmation.
- Added drag-to-select recognition inside full screenshots.
- Added recognized-clue handoff for bosses, vouchers, tags, decks, stakes, and shop slots.
- Added persistent run actions, undo, and named branch checkpoints.
- Replaced the temporary tiled backdrop with a stable CPU port of the game's paint-field background.
- Added asset-catalog and image-matcher regression suites.
